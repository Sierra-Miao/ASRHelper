API 高级设置

默认 100 句段，可设为 10–500。长句会按输出预算提前分批；若希望每批更多，可适当提高最大输出 Token 和超时时间。

API 模式将转写表格发送给你配置的服务商；Agent 模式由你把交接包交给客户端。原始音频默认在本机；Qwen 在线参考会上传音频。配置及 Key 保存在本机 data/settings.json，重启自动恢复，请勿分享密钥文件。

官方模型资料

双模型组合

一个传统模型提供主稿、时间和说话人，一个 LLM 语音模型提供疑难参考。选择组合后，点击“启用此组合”。

Qwen3-ASR 在线语音识别

使用官方 DashScope SDK，默认模型 qwen3-asr-flash。不下载 Qwen 权重。上传音频可能产生服务费用，API Key 必须与所选地域匹配。此处独立于文字校对 API。

适合内存较小、希望使用云端 LLM 识别作参考的长录音；支持多语言自动识别和 ITN 数字规范化，参数量以服务商披露为准。每块参考只标注音频范围，沿用传统主稿的时间与说话人。官方接口与限制

北京：https://dashscope.aliyuncs.com/api/v1；新加坡：https://dashscope-intl.aliyuncs.com/api/v1；也支持业务空间专用域名。

本机通过 FFmpeg 检测低于 −40 dB、持续至少 0.5 秒的停顿；每段满 10 秒后，在首个合适停顿的中点切割，每段 10–60 秒。尾部也检查停顿，避免切出不足 10 秒的小块；超过 60 秒无合适停顿时强制切分。原录音不足 10 秒则整段上传。配置与 Key 保存于本机 JSON，重启自动恢复；参考时间是音频块范围，主稿时间不变。
